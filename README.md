# 📘 Facebook Login Poster using Python

This project allows you to post status updates and images to Facebook using Python and the Facebook Graph API. It uses an access token for secure authentication and supports posting to your personal timeline or a Facebook Page you manage.

---

## 🚀 Features

- Post plain text messages to Facebook
- Upload and share images with captions
- Post to user timeline or Facebook Page
- Simple and lightweight (uses `requests`)

---

## 🔧 Requirements

- Python 3.7 or higher
- A Facebook Developer Account
- A valid **Graph API Access Token**
